# Python Activity-Based Learning (ABL)

This repository contains Python Activity-Based Learning projects with source code, documentation, algorithms, pseudocode, flowcharts, and test cases.

## Project 1: Student Marks and Grade Calculator

**Folder:** `01_student_grade_calculator/`

### Features
- Accepts marks for five subjects (0–100 each)
- Validates each mark
- Calculates total and percentage
- Assigns a sample grade using `if-elif-else`

### Run
```bash
python main.py
```

See the project's `documentation.md` for the problem statement, algorithm, pseudocode, flowchart, and test cases.

> Note: The grade boundaries are practice assumptions. Follow your faculty's rules if they differ.
